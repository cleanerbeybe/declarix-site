## GMR route/reference selection

https://www.gov.uk/guidance/create-a-goods-movement-reference (capture04)

Under EU to Great Britain / Common Transit Convention:
> You must not include associated import declaration references in the goods movement reference for goods moving under Common Transit Convention.
> You can choose to include the safety and security import entry summary declaration MRNs, but it is not mandatory.

Applied: replace collect-every-reference direction with required route/procedure references; explicitly exclude associated import references on EU-to-GB common transit. Optional ENS reference in a GMR does not remove a separate ENS filing duty. No change to OPEN/NOT_FINALISABLE controls, physical matching or inspection instruction.

> If you have not received a notification of discharge either digitally or via letter, the movement can be assumed to be open and the MRN still in use.

The page separately explains evidence of ending transit for a specific-MRN enquiry. Applied: require separate discharge notification; do not equate destination arrival with discharge. No guarantee amount, message-version, complete NCTS phase or customs-office procedure validation claimed.
